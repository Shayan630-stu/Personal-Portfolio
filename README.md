# Personal Portfolio Website

A personal portfolio website developed to showcase my profile, skills, and work in a simple and professional way. This project is built using HTML, CSS, and JavaScript with a focus on clean design and user-friendly navigation.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
Personal-Portfolio/
│
├── index.html
├── style.css
├── script.js
├── pic.jpeg
└── s.jpeg
```

## Features

- Personal portfolio website
- Clean and simple user interface
- Custom styling using CSS
- JavaScript functionality
- Image integration
- Responsive design

## Getting Started

To run this project locally:

1. Clone the repository:

```bash
git clone https://github.com/Shayan630-stu/Personal-Portfolio.git
```

2. Open the project folder.

3. Open `index.html` in your web browser.
